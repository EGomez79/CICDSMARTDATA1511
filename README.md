# CICDSMARTDATA1511
Este repositorio contiene los objetos necesarios para la practica final de la especializacion de Ingenieria de Datos con Databricks e IA.
Se trata de cubrir sobre todo el despliegue de objetos al Workspace productivo en Databricks enviando objetos o cambios creados en el ambiente de desarrollo desde un archivo .yml desde este archivo de crearan los objetos necesarios para crear un Job, armar un ETL y ejecutar el job.
Con esta practica se cubre la parte cd CI/CD enlazando gitHub y Databrics.
